# 小吉 1.1.0

## 發布狀態

這是 `1.1.0` 的正式發行說明。本版本已完成本機檢查與真實 Discord 伺服器逐項驗收，並在正式發布前清除測試資料。

## 新增功能

- 新增文字接龍：檢查 2–6 字的專案詞庫詞彙、接續字、重複詞與輪替使用者；有效答案會收到 `✅`。
- 新增數字接龍：支援安全、精確的整數與 `+ - * /` 括號運算式驗證；結果符合目標才算通過並收到 `✅`。
- 新增每日猜謎：台北時間 10:00 發題、21:30 公布標準答案；有效參與者獲得 30 吉幣，答對者再獲得 50 吉幣。
- 新增每日議題：台北時間 00:00 發布開放式安全議題；截止前有效參與者獲得 30 吉幣。
- 新增六種跨伺服器持久化聊天風格：清純可愛妹妹風、御姐風、霸總風、冰冷風、傲嬌風與病嬌風。
- 新增俄羅斯方塊、數字配對與數獨三種伺服器權威遊戲，以及依規則結算的吉幣獎勵。
- 新增自願啟用、可隨時停止且跨伺服器持久化的文字戀愛模式。
- 將可花用餘額、累計賺取與累計支出改為 Discord 使用者跨伺服器共用的全域吉幣錢包；銀行、定存、籌碼、貸款及所有商店規則與商品紀錄仍依各伺服器獨立。
- 新增小吉官方網站，顯示去識別化的伺服器採用量、台北當日使用量與目前狀態。
- 新增即時狀態頁，逐項標示公開功能為正常、維護中或損壞。
- 新增正式 GitHub Release 公告：只處理 `1.0.0` 起的穩定正式版本，不把草稿、預發版、提交、分支或一般功能更新當成公告來源。

## 安全與資料契約

- 聊天風格與文字戀愛模式以 Discord 使用者帳號作為內部穩定鍵，跨伺服器保留，直到使用者再次變更或停止。
- 每日活動與遊戲獎勵由小吉後端驗證並以冪等方式結算；瀏覽器端不能自行提交分數或獎勵金額。
- 舊版各伺服器的可花用餘額與累計數值只在 schema v20 升級時按使用者安全加總一次；原始資料保留為禁止寫入的封存，遷移清單、摘要、總和與交易 revision 會在重啟時驗證。
- `/coin-admin add/remove/set/reset-user` 會影響使用者的全域錢包，因此僅小吉 bot owner 可執行；伺服器管理員不能繞過此限制。
- 官網與狀態 API 僅提供去識別化彙總與白名單狀態，不公開伺服器、頻道、成員、訊息或 Discord ID。
- 小吉所有回覆仍遵守既有安全、隱私與身分規則；私人音樂實驗不屬於 `1.1.0` 公開功能。

## 發布驗證

- 本機完整測試、網站檢查、依賴稽核與正式環境設定檢查均已通過。
- 發布前已保留可用的程式碼回滾版本，並以受控備份保護資料清理流程。
- 真實 Discord 驗收已涵蓋上述新增功能、獎勵、跨伺服器風格與文字戀愛模式，結果均通過。
- 正式版本建立後，公告服務只會向已審核且明確設定的頻道發布，並以持久化紀錄避免重複公告。
